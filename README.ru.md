\# CGMonitor



\[English](README.md) | \*\*Русский\*\*



> ⚠️ \*\*Не проверяйте приложение в онлайн-играх с античитом.\*\* Совместимость с античит-системами (Easy Anti-Cheat, BattlEye, Vanguard, FACEIT AC и др.) \*\*не проверялась\*\*. Оверлей использует перехват Present-событий (PresentMonFps) и доступ к аппаратным датчикам, что теоретически может быть воспринято античитом как подозрительная активность. Используйте на свой риск — в офлайн-играх, в одиночных режимах или в тестовой среде.



Прозрачный оверлей для Windows, отображающий в реальном времени ключевые показатели системы: температуру, частоту, загрузку и энергопотребление CPU и GPU, использование RAM и график фреймтайма. Рисуется поверх других окон — предназначен для мониторинга во время игр или работы.



Оверлей — самостоятельное перетаскиваемое окно, не мешающее взаимодействию с другими программами.



\---



\## Обязательные условия



\### Драйвер PawnIO



Данные с аппаратных датчиков получаются через \*\*LibreHardwareMonitor\*\*. Требуется драйвер \*\*PawnIO\*\* для доступа к низкоуровневым датчикам (особенно на AMD Ryzen и NVIDIA/AMD GPU).



Без PawnIO:



\- Температура CPU может показываться как `0°C` или `N/A`

\- Частота CPU может быть недоступна

\- Энергопотребление CPU и GPU может не выводиться

\- Некоторые датчики GPU могут быть недоступны



Скачайте PawnIO с официального сайта проекта или установите из архива CGMonitor. После установки перезапустите приложение.



\### Запуск от имени администратора



Приложение \*\*обязательно\*\* должно запускаться от имени администратора. LibreHardwareMonitor и PawnIO требуют повышенных привилегий для доступа к датчикам. Без прав администратора большинство показателей будет недоступно, а оверлей будет показывать нули или пустые значения.

\## Как считаются параметры



\### CPU



| Параметр | Источник | Детали |

|---|---|---|

| \*\*Температура\*\* | `Core (Tctl/Tdie)` → `CPU Package` | Приоритет AMD `Tctl/Tdie`; иначе `CPU Package` (Intel). Цвет: голубой (норма), оранжевый (75–90°C), красный (>90°C). |

| \*\*Частота\*\* | Максимум по физическим ядрам | Перебор `Clock`-датчиков с `Core`, исключая `SMU`, `Effective`, `Average`, `Max`. Наибольшее значение в МГц. |

| \*\*Загрузка\*\* | `CPU Total` (`Load`) | Общая загрузка CPU в процентах от LibreHardwareMonitor. |

| \*\*Энергопотребление\*\* | `Package` (`Power`) | Общее энергопотребление пакета CPU в ваттах. |



\### GPU



| Параметр | Источник | Детали |

|---|---|---|

| \*\*Температура\*\* | `GPU Core` / `GPU Package` / `GPU Hot Spot`; ADL для AMD mobile | Дискретные GPU — датчики LibreHardwareMonitor. AMD APU дополнительно используют \*\*ADL\*\* (`atiadlxx.dll`, `ADL2\_OverdriveN\_Temperature\_Get`, тип `EDGE`). |

| \*\*Загрузка\*\* | `Gpu Load` / `D3D 3D` | Сглаживание с коэффициентом 0.15. В процентах. |

| \*\*Энергопотребление\*\* | `GPU Package` / `GPU Core` / `GPU Total` / `GPU ASIC` / `Total Power` | Для AMD APU без датчика мощности: питание пакета минус сумма `Core #N`, не ниже нуля. |

| \*\*FPS\*\* | \*\*PresentMonFps\*\* | Отслеживается процесс переднего плана через `GetForegroundWindow` + `GetWindowThreadProcessId`. При смене процесса трекинг перезапускается. |

| \*\*Frametime\*\* | Из FPS | `1000 / FPS`, 6 точек с jitter на обновление (±0.5 мс, или ±2 мс при FPS ниже 40). Кольцевой буфер на 100 значений. |



> ⚠️ \*\*Встроенная графика Intel (HD/UHD/Iris Xe)\*\* \*\*не имеет отдельного датчика температуры GPU\*\*. Температура для Intel iGPU не отображается — это ограничение оборудования, а не приложения.



\*\*График фреймтайма:\*\* 100 последних значений, шкала 0–50 мс. Зелёная линия ниже 30 мс, красная выше. Красный пунктир = 16.6 мс (60 FPS). Максимум — в правом верхнем углу.



\### RAM



| Параметр | Источник | Детали |

|---|---|---|

| \*\*Загрузка\*\* | `Memory` (`Load`) | Процент использования RAM. |

| \*\*Использовано\*\* | `Memory Used` (`Data`) | Использованная память в ГБ. |

| \*\*Всего\*\* | `Memory Used` + `Memory Available` | Сумма использованной и доступной памяти, в ГБ. |

\## Когда данные могут не выводиться



1\. \*\*Не установлен драйвер PawnIO\*\* — температура, частота и энергопотребление CPU/GPU могут быть недоступны или равны нулю.

2\. \*\*Запуск без прав администратора\*\* — большинство датчиков будет недоступно.

3\. \*\*Встроенная графика Intel\*\* — нет отдельного датчика температуры; температура GPU не отображается.

4\. \*\*Датчик отсутствует на конкретном оборудовании\*\* — некоторые ноутбуки не предоставляют датчик температуры GPU. Для AMD mobile используется ADL; если и он недоступен — температура не показывается.

5\. \*\*FPS не отображается\*\* — в фокусе рабочий стол/проводник, или приложение не использует PresentMon-совместимый метод вывода кадров (некоторые Vulkan/OpenGL игры, старые приложения). Также если PresentMonFps не может получить PID (FPS также может отображаться на рабочем столе — это особенность PresentMonFps).

6\. \*\*Энергопотребление GPU отсутствует\*\* — нет датчика мощности на некоторых мобильных GPU; расчёт через разницу также может не дать результата (некоторые старые видеокарты не определяют потребляемую мощность, поэтому мощность может совпадать с потребляемой мощностью процессора).

7\. \*\*RAM отображается некорректно\*\* — датчики `Memory Used` / `Memory Available` отсутствуют на некоторых материнских платах.

8\. \*\*Оверлей не появляется\*\* — запуск без прав администратора, или PawnIO не установлен и LibreHardwareMonitor не инициализируется. Также проверьте блокировку антивирусом.
